  - **Set by a prompt.** `send` sets it as it records the prompt's event. That is the one path for a launch's opening prompt and every prompt after, so nothing is written for it and nothing about sending can fail or slow.
  - **Read back at start-up.** `liveLocked` already reads every event of a log as it opens it, and start-up's recovery opens every conversation's.
